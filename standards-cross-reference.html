Class markings: "8.8" means Rm ≥ 800 MPa and yield/tensile ratio 0.8 → 640 MPa. Class 12.9 is typically marked with 3 radial dash marks on the head.

How the class number works

8.8 → first digit = Rm/10 (800 MPa) · second digit = Rp0.2/Rm × 10 (0.8 → 640 MPa)

Stainless steel uses a different system (ISO 3506): A2-70 (304 stainless, 700 MPa cold worked), A2-80, A4-70/A4-80 (316 stainless), and C4-70 (duplex). Nuts use property classes 6, 8, 10, 12 — pair class 8 nuts with 8.8 bolts, 10 with 10.9, 12 with 12.9.

FAQ

Can I substitute DIN 933 for ISO 4017 in a BOM?

Dimensionally yes — same part, different issuing body. Keep the grade (8.8 etc.), thread tolerance (6H/6g) and surface finish identical. Many buyers list both, e.g. "DIN 933 / ISO 4017 M10×40 8.8 zinc plated".

What nut goes with a 10.9 bolt?

A property class 10 nut (ISO 4032 class 10). Using a weaker nut shifts stripping into the nut — which is by design (nuts are cheaper to replace than the joint). Never pair a class 8 nut with a 12.9 bolt.

What is the difference between ISO 4032 and ISO 10511?

ISO 4032 is a standard hex nut (style 1); ISO 10511 is the nylon-insert self-locking version (DIN 985, "nylock"). Use locking nuts where vibration loosening is a risk, or apply threadlocker to standard nuts.

A2-70 vs A4-80 — when to use which?

A2 (304 stainless) for indoor/low-corrosion, non-marine use. A4 (316 stainless, with molybdenum) for marine, chemical, coastal and food environments. A4-80 is also the safer choice for exterior structural connections.
